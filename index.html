Abstract

Text-guided selective video-to-audio generation is important because users often want one specific sound, rather than every sound visible in a video. However, progress has been limited by the lack of clean multitrack data, and previous approaches such as SelVA rely on automatically constructed, noisy supervision. We address this limitation with a human-curated 3.3K multitrack dataset containing videos, isolated source stems, and source-level captions.

More importantly, we rethink selective V2A as an audio-conditioned V2A problem. Instead of training a text-only model to learn every possible sound, we exploit pretrained AC-V2A models that already transfer an audio reference into a video. By probing their conditioning pathways, we find that source selection is strongly controlled by the semantic representation of the reference audio: a clean reference can suppress unrelated visible events, not merely transfer timbre. Based on this finding, we propose CSIO, which converts a text query into the source-selective reference representation normally obtained from audio. This allows a frozen AC-V2A model to perform text-guided selective generation without massive end-to-end training, combining text-based source selection with the strong synchronization and acoustic rendering ability of pretrained AC-V2A models.

In three steps

Data

Clean multitrack supervision

SelFoley3.3K: 3,357 videos with isolated source stems and a caption per source, every stem audited by human listeners. Prior text-guided models learned from automatically constructed, noisy targets instead.

Finding

The reference selects the source

Probing the conditioning pathways of pretrained audio-conditioned V2A models shows that source selection is governed by the semantic representation of the reference audio. A clean reference suppresses unrelated visible events; it does not only transfer timbre.

Method

CSIO: text in place of the reference

CSIO converts a text query into the source-selective reference representation that the model normally obtains from audio. The AC-V2A backbone stays frozen and keeps its synchronization and acoustic rendering ability.

Probing the conditioning pathways

With a clean, single-source reference the model renders that source and leaves the other visible events silent; with a mixed reference the mixture comes back. Intervening on the semantic representation of the reference moves the selection, which is why CSIO targets exactly that representation.

How SelFoley generates one source

A text query goes through CSIO and comes out as the source-selective reference representation. The frozen AC-V2A backbone receives it in place of a reference clip, together with the silent video, and renders the selected source alone. No reference audio is needed at inference and no end-to-end retraining of the backbone.
